## [0.1.0] - 2026-09-24

### Added

- Initial release of the HackerOne Theme extension for Zed.
- **HackerOne Dark** — dark theme variant adapted from the official HackerOne VS Code theme.
- **HackerOne Light** — light theme variant based on the HackerOne Design System (H1/U1).
- Support for Zed's automatic system appearance switching between dark and light modes.
- Full syntax highlighting coverage across code, markdown, comments, and keywords.
- Styled Zed UI chrome: tabs, status bar, panels, modals, and integrated terminal palette.
- Extension manifest (`extension.toml`) prepared for the Zed Extension Registry.
- Project documentation with cross-platform shortcuts, configuration guide, design attribution, and MIT license.
